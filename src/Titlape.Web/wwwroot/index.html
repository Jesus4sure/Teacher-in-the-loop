How the platform is built

6-layer architecture with cross-cutting Zero-Trust security and communication
Layer 6 · AutonomousMaster Orchestrator, Student PWA, Teacher Portal
Layer 5 · IntelligenceDiagnostic, Socratic, Localization, Safety agents
Layer 4 · ContextCurriculum RAG, student memory (BKT), pathways
Layer 3 · XAI / RAIGuardrails, CoT traces, SHAP, bias audit, audit chain
Layer 2 · ModelEdge SLM (llama.cpp) / cloud (vLLM), signature checks
Layer 1 · DataPII gateway, AES-256, CRDT offline sync, vectors
